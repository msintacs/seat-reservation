# Seat Reservation

동시 요청 상황에서 좌석 선점과 예매 처리를 학습하는 백엔드 중심 프로젝트입니다.

## 현재 상태
프로젝트 초기 준비 단계입니다. Spring Boot 애플리케이션 진입점과 기본 컨텍스트 테스트 골격만 있으며, 아래 예매 기능은 아직 구현되지 않았습니다. 이번 문서 준비 과정에서는 빌드와 테스트를 실행하지 않았습니다.

## 계획된 기능
- 일반 회원가입·로그인과 Google 로그인
- 공연·회차·좌석 조회, 관리자 공연 등록
- 제한 시간 내 다중 좌석 선점과 좌석 변경
- 모의 결제와 예매 내역 조회
- 전체·부분 취소와 모의 환불
- 동시 요청·중복 요청·만료 경계 검증

실제 금전 이동, 대기열, 외부 배포는 현재 범위에 포함하지 않습니다.

## 기술 구성
| 구분 | 현재/계획 |
|---|---|
| 백엔드 | Java 21, Spring Boot 4.1.1, Spring Web MVC 설정됨 |
| 빌드 | Gradle Wrapper 9.7.1 선언 |
| 데이터 | 로컬 MySQL, Docker Redis 사용 예정 |
| 프론트 | React, TypeScript, Tailwind CSS, Axios 도입 예정 |
| 인증 | 서버 세션·쿠키, 개발 프록시 구성 예정 |

현재 저장소에는 프론트, DB 연결, Redis 실행 설정이 아직 없습니다. 실행·테스트 절차는 기능 구현과 실제 확인 후 추가합니다.

## 설정 관리
비밀키와 비밀번호는 환경변수 또는 Git에서 제외한 로컬 설정으로 주입합니다.
